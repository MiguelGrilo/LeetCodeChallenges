# 9. Palindrome Number

Given an integer `x`, return `true` if `x` is a ***palindrome***, and `false` *otherwise*.

---

### Example 1:
**Input:** `x = 121`  
**Output:** `true`  
**Explanation:** 121 reads as 121 from left to right and from right to left.

### Example 2:
**Input:** `x = -121`  
**Output:** `false`  
**Explanation:** From left to right, it reads -121. From right to left, it becomes 121-. Therefore it is not a palindrome.

### Example 3:
**Input:** `x = 10`  
**Output:** `false`  
**Explanation:** Reads 01 from right to left. Therefore it is not a palindrome.

---

### Constraints:
* `-2³¹ <= x <= 2³¹ - 1`

---

**Follow up:** Could you solve it without converting the integer to a string?

<summary> <h2>Solution</h2> </summary>
  
## With .ToString()
```csharp
public class Solution {
    public bool IsPalindrome(int x) {
        string str = x.ToString();
        int n = str.Length;

        for (int i = 0; i < n / 2; i++) 
        {
            if (str[i] != str[n - 1 - i]) 
            {
                return false;
            }
        }

        return true;
    }
}
```  
  
## Without .ToString()
```csharp
public class Solution {
    public bool IsPalindrome(int x) {
        // Exceptions (Negative numbers or numbers that finish in 0)
        if (x < 0 || (x % 10 == 0 && x != 0)) {
            return false;
        }

        int reverse = 0;
        while (x > reverse) {
            int lastDIgit = x % 10;
            reverse = (reverse * 10) + lastDIgit;
            x /= 10;
        }

        // For numbers with an even number of digits (e.g., 1221), x will be 12 and reversed will be 12.
        // For numbers with an odd number of digits (e.g., 12321), x will be 12 and reversed will be 123.
        // We use /10 to ignore the middle digit.
        return x == reverse || x == reverse / 10;
    }
}
```
