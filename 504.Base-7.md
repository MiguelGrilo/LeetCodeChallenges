# 504. Base 7 [Challenge](https://leetcode.com/problems/base-7/description/)

Given an integer `num`, return *a string of its **base 7** representation*.

---

### Example 1:

**Input:** `num = 100`  
**Output:** `"202"`  

### Example 2:

**Input:** `num = -7`  
**Output:** `"-10"`  

---

### Constraints:

* $-10^7 \le \text{num} \le 10^7$

---

<details>
<summary><h2>Solution</h2></summary>

```csharp
public class Solution {
    public string ConvertToBase7(int num) {
        if (num == 0) return "0";

        bool Negative = num < 0;
        num = Math.Abs(num);
        string result = "";

        while (num > 0) {
            result = (num % 7) + result; 
            num /= 7;
        }

        return Negative ? "-" + result : result;
    }
}
```
