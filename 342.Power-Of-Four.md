# 342. Power of Four [Challenge](https://leetcode.com/problems/power-of-four/description/)

Given an integer `n`, return `true` *if it is a power of four. Otherwise, return* `false`.

An integer `n` is a power of four, if there exists an integer `x` such that $n == 4^x$.

---

### Example 1:

**Input:** `n = 16`  
**Output:** `true`  

### Example 2:

**Input:** `n = 5`  
**Output:** `false`  

### Example 3:

**Input:** `n = 1`  
**Output:** `true`

---

### Constraints:

* $-2^{31} \le n \le 2^{31} - 1$

---

**Follow up:** Could you solve it without loops/recursion?

```csharp
public class Solution {
    public bool IsPowerOfFour(int n) {
        // if ( n == 1 ) return true;
        // if ( n <= 0 || n % 4 != 0) return false;

        // return IsPowerOfFour(n/4);


        // This is a bitwise trick to check if a number is a power of 2.
        // Binary power of 2 has only one '1' bit (e.g., 4 is 100, 8 is 1000).
        // Subtracting 1 flips all bits after the '1' (e.g., 4-1=3, which is 011).
        // Using AND (&) results in 0 only if there's exactly one bit set.
        
        // A power of 2 is a power of 4 if its only set bit is in an even position.
        // Mathematically, (4^n - 1) is always divisible by 3. 
        // Therefore, any power of 4 divided by 3 always leaves a remainder of 1.        
        return n > 0 && (n & n - 1) == 0 && n % 3 == 1;
    }
}
```
