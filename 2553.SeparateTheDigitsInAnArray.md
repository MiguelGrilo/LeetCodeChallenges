# 2553. Separate the Digits in an Array [Challenge](https://leetcode.com/problems/separate-the-digits-in-an-array/description/)

Dado um array de inteiros positivos `nums`, devolva um array `answer` que consista nos dígitos de cada inteiro em `nums` após separá-los na mesma ordem em que aparecem em `nums`.

Separar os dígitos de um inteiro é obter todos os dígitos que ele tem na mesma ordem.

Por exemplo, para o inteiro `10921`, a separação dos seus dígitos é `[1,0,9,2,1]`.

---

### Example 1:
**Input:** `nums = [13,25,83,77]`  
**Output:** `[1,3,2,5,8,3,7,7]`  
**Explanation:** 
- A separação de `13` é `[1,3]`.
- A separação de `25` é `[2,5]`.
- A separação de `83` é `[8,3]`.
- A separação de `77` é `[7,7]`.  
`answer = [1,3,2,5,8,3,7,7]`. Note que `answer` contém as separações na mesma ordem.

### Example 2:
**Input:** `nums = [7,1,3,9]`  
**Output:** `[7,1,3,9]`  
**Explanation:** A separação de cada inteiro em `nums` é ele próprio.   
`answer = [7,1,3,9]`.

---

### Constraints:
* `1 <= nums.length <= 1000`
* `1 <= nums[i] <= 10^5`

```csharp
class Solution {
    public int[] SeparateDigits(int[] nums) {
        List<int> result = new List<int>();
        for (int i = nums.Length - 1; i >= 0; i--) {
            int x = nums[i];
            while (x > 0) {
                result.Add(x % 10);
                x /= 10;
            }
        }
        result.Reverse();
        return result.ToArray();
    }
}
```

public class Solution {
    public int[] SeparateDigits(int[] nums) {
        List<int> result = new List<int>();

        for (int i = 0; i < nums.Length; i++) {            
            string str = nums[i].ToString();            
            
            foreach (char digit in str) {
                result.Add(digit - '0'); 
            }
        }
        return result.ToArray();
    }
}
